# LabLua at Google Summer of Code

![](http://www.lua.inf.puc-rio.br/images/site_header.png)

[LabLua](http://www.lua.inf.puc-rio.br/) is a research laboratory at PUC-Rio dedicated to
programming languages, founded in 2004 by Roberto Ierusalimschy, the chief architect of
[Lua](https://www.lua.org/). We have been a mentoring organization in
[Google Summer of Code](https://summerofcode.withgoogle.com/) since 2014, umbrella-ing projects
from across the Lua ecosystem: Lunatik, Pallene, Teal, LuaRocks, LuaSQL, LPeg, terminal.lua,
Atmos and the lunarmodules libraries, among others.

This repository holds the ideas list of every edition and, from 2026 on, the results of each one.

## → [Project Ideas List for GSoC 2026](2026/ideas.md)

## For contributors

Everything we expect from an application, in order:

1. **Talk to us first.** Proposals sent with no previous contact with a mentor are not evaluated.
2. **Make meaningful contributions** to the code base of the project you want to work on.
3. **Write your own proposal**, using the [application template](apply.md), and send it in time.

The ideas list linked above spells all of this out, and has the details of each project: mentors,
prerequisites, size, skill level, Matrix room, and what is and isn't allowed regarding AI usage.
You may also bring your own idea. Either way, don't leave it to the last minute =).
