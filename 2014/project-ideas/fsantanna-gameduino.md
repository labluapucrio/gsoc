## Project

Porting Gameduino demos to the programming language C&eacute;u.

### Brief explanation

Gameduino [1] is an Arduino-based [2] open-source hardware platform for games.
It is composed of a touchscreen, an embedded GPU, headphone jack, 
accelerometer, and a microSD slot.
The associated software package contains dozen of demos and four complete games 
(e.g.  Space Invarders and Chess) developed in C.
Gameduino was a successful Kickstarter project in 2013 [3].

C&eacute;u [4] is a concurrent programming language that offers a safer and 
higher-level alternative to C.
It targets embedded systems such as Arduino.
C&eacute;u was designed in the Lablua.

### Expected results

* Port the Gameduino demos from C to C&eacute;u.
* Compare the codebases in C and C&eacute;u with respect to quantitative 
  measures such as lines of code, memory consumption and CPU usage.

### Knowledge prerequisites

C and C&eacute;u:

* C is mandatory.
* C&eacute;u is a C-based language and can be learned during the project.

### Skill level

Medium
